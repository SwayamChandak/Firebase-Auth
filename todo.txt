2. File Compression and Storage API
    Purpose: Provide REST API to upload files, compress them (ZIP/GZIP), and store for retrieval.

    Core Functions:
    POST /upload: Accept files, compress them using server-side logic.
    Store compressed files in S3/minio/local FS.
    Save metadata in PostgreSQL (filename, compression ratio, owner, timestamps).
    GET /download/{file_id}: Serve the compressed file with download headers.

    Optional: background compression via Celery/RQ.
    Tech Stack: Django/FastAPI, Celery, PostgreSQL, S3-compatible storage, zlib/patool.
3. Secure Notes Storage with Expiry

    Integrate with scholar share
    Purpose: Allow users to store sensitive notes securely with automatic deletion after a specified time.

    Core Features:
    POST /notes: Accept note content, optional expiry time (e.g., 1 hour, 1 day).
    Encrypt note content server-side using AES or Fernet before storage.
    Generate a unique ID or access token for retrieval.
    Store encrypted content, creation timestamp, and expiry in PostgreSQL.
    GET /notes/{id}: Decrypt and return note if it hasn't expired; else return 410 Gone.
    Background job (Celery/RQ) to periodically delete expired notes.

    Optional Enhancements:
    One-time view (note deletes after first read).
    Add role based access. generate schema better than scholar share
    Password-protected notes.
    Burn-after-read timer.
    Rate limiting to prevent abuse.

    Tech Stack: FastAPI/Django, PostgreSQL, cryptography library, Celery, Redis (for task queue).
